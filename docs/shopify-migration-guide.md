# העברת LIETO ל-Shopify: מדריך צעד אחרי צעד

החנות שלך: **cwa4pb-4z.myshopify.com**
כל השלבים נעשים מתוך הניהול של Shopify, בחלון של החשבון העסקי.

---

## 1. העלאת העיצוב (5 דקות)
1. **Online Store ← Themes**
2. למטה: **Add theme ← Upload zip file** ← בוחרים את הקובץ `LIETO-theme.zip`
3. כשהעלייה מסתיימת: **Customize** כדי לראות, ואחרי שהכל מוכן **Publish**.

## 2. ייבוא המוצרים (2 דקות)
1. **Products ← Import** ← בוחרים את `products.csv` ← **Import products**.
2. נכנסים לכל מוצר ומעלים את התמונות מהתיקייה `images`, לפי הסדר (1, 2, 3):

| מוצר | תיקייה |
|---|---|
| שרשרת חבל שזורה לגבר 2 מ״מ · גוון כסוף | `images/silver-rope-chain-2mm` (תמונה + 2 סרטונים) |
| שרשרת פנינים וקובנית שחורה לגבר · Noir & Pearl | `images/noir-pearl-necklace` |
| סט שרשרת וצמיד לגבר בשזירה קלאסית · גוון כסוף | `images/rope-chain-bracelet-set` |

**חומר הסט:** פלדת אל-חלד בגוון כסוף (אושר). לא לציין כסף או זהב אמיתי.

## 3. קטגוריות (5 דקות)
**Products ← Collections ← Create collection**, ובכל אחת בוחרים **Automated** עם התנאי **Product type is equal to**:

| שם האוסף | Product type |
|---|---|
| טבעות | טבעות |
| שרשראות ותליונים | שרשראות |
| צמידים | צמידים |
| עגילים | עגילים |
| סטים | סטים |

## 4. תפריט עליון
**Online Store ← Navigation ← Main menu**: חנות (All products), קטגוריות, מבצעים, משלוחים, מעקב הזמנה.

## 5. אזור הפתיחה (Customize)
בעורך העיצוב לוחצים על **אזור פתיחה**:
- **המוצר שמוצג:** סט שרשרת וצמיד.
- **תמונה לאזור הפתיחה:** `images/home-hero/hero-set-gold.jpg`.
- **מוצרים מומלצים:** בוחרים את האוסף "All products" או "שרשראות ותליונים".
- **עמוד תנאי המבצע:** בוחרים אותו אחרי שלב 7.

ב**קטגוריות** מחברים כל קטגוריה לאוסף שלה. ב**מוצרים מאוסף** בוחרים "All products".

## 6. קודי הנחה
**Discounts ← Create discount ← Amount off order**:

| קוד | הנחה | תנאים |
|---|---|---|
| `LAUNCH15` | 15% | עד 31.12.2026, פעם אחת ללקוח |
| `LIETO10` | 10% | פעם אחת ללקוח |
| `PAIR15` | 15% | מינימום 2 פריטים בעגלה |

אם משנים אחוז או תאריך, מעדכנים גם ב-Customize, באזור הפתיחה ובהטבות.

## 7. מדיניות ועמודים
- **Settings ← Policies:** ממלאים מדיניות החזרות, פרטיות, משלוחים ותנאי שימוש. אפשר להעתיק את הנוסח מהאתר הקודם, ולעבור עליו עם עורך דין.
- **Online Store ← Pages:** יוצרים עמוד **הצהרת נגישות** ועמוד **תנאי המבצעים** (נוסחים למטה).
- בהגדרות העיצוב (Theme settings ← חנות) בוחרים את עמוד הצהרת הנגישות. כך הוא מופיע בכפתור הנגישות ובתחתית.

## 8. משלוחים
**Settings ← Shipping and delivery**:
- משלוח רגיל ₪19.
- משלוח חינם מעל ₪199.
- בתיאור המשלוח כותבים "10–25 ימי עסקים, עם מספר מעקב".

## 9. DSers: חיבור המוצרים לספק
**Apps ← DSers ← Products ← Mapping**, ולכל מוצר מדביקים את הקישור ובוחרים את האפשרות:

| מוצר | קישור ספק | מה לבחור |
|---|---|---|
| שרשרת שזורה 2 מ״מ | https://he.aliexpress.com/item/1005007793853397.html | Metal Color: 2MM Width + האורך שהלקוח בחר |
| שרשרת פנינים | https://he.aliexpress.com/item/1005006216490067.html | 1 size (לבדוק שזו השרשרת ולא הצמיד) |
| סט שרשרת וצמיד | https://he.aliexpress.com/item/1005006916236066.html | 20cm and 60cm |

בהגדרות DSers מוסיפים הערה קבועה לספק:
> Dropshipping order. Please do NOT include any invoice, receipt, price tag or promotional material. Plain neutral packaging only. Thank you!

## 10. לפני פתיחה
- **Settings ← Payments:** PayPal וחברת סליקה.
- **Settings ← Checkout:** לוגו וצבעים.
- **Settings ← Domains:** חיבור הדומיין.
- **Online Store ← Preferences:** עד הפתיחה משאירים סיסמה. דף הסיסמה כבר מעוצב ואוסף מיילים.
- **הזמנת ניסיון** אחת מתחילה ועד הסוף.
