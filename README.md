# LIETO

חנות תכשיטי אופנה לגברים מפלדת אל-חלד.

## מה יש כאן

| תיקייה | מה בה |
|---|---|
| `site/index.html` | האתר המלא: חנות, עגלה, תשלום, ממשק ניהול, קבלות וגיבוי לדרייב. רץ כ-Artifact ב-claude.ai, כי הוא משתמש בסביבה של claude.ai (`window.claude`) למסד הנתונים, להעלאת קבצים ולחיבור לדרייב. |
| `shopify-theme/` | ערכת העיצוב ל-Shopify (גרסה 1.0.3, גברים), כולל אזור הלוקבוק. |
| `media/hero/` | סרטון הפתיחה: גרסה רחבה למחשב וגרסה אנכית לטלפון, עם תמונות כיסוי. |
| `media/products/` | תמונות 14 המוצרים. |
| `media/lookbook/` | תמונות הלוקבוק. |
| `products/products.json` | נתוני המוצרים: שם, קטגוריה, חומר, תיאור, אורכים, גימורים ומחיר. שדות `img` ו-`media` מצביעים על קבצים בתוך ה-Artifact (`/_blob/...`). הקבצים עצמם נמצאים ב-`media/products/`. |
| `docs/handoff.md` | סיכום להמשך עבודה עם Claude מחשבון אחר. |
| `docs/shopify-migration-guide.md` | מדריך הקמת החנות ב-Shopify. |

## העלאת העיצוב ל-Shopify

**דרך 1, קובץ zip:** דוחסים את התוכן של `shopify-theme/` לקובץ zip, כך שהתיקיות `layout`, `sections` ושאר התיקיות יהיו בשורש הקובץ. ב-Shopify: חנות מקוונת ← ערכות נושא ← הוספת ערכת נושא ← העלאת קובץ zip.

**דרך 2, חיבור ישיר לגיטהאב:** חנות מקוונת ← ערכות נושא ← הוספת ערכת נושא ← **התחברות מ-GitHub** ← בוחרים את המאגר ואת הענף. Shopify מצפה לקבצי העיצוב בשורש הענף, ולכן מחברים ענף שבו התוכן של `shopify-theme/` נמצא בשורש.

## כללים לתוכן

- **ביקורות ודירוגים:** בלי ביקורות או דירוגים מומצאים, ובלי "נמכר ביותר" לפני שיש מכירות.
- **מחירים:** בלי מחיר מחוק שהמוצר לא נמכר בו בפועל.
- **הבטחות:** בלי הבטחות שהספק לא אישר.
- **חומר:** מתוארים כתכשיטי אופנה מפלדת אל-חלד, לא כסף או זהב.
